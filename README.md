# Testimonial Cards Component

Proyek ini adalah koleksi berbagai gaya kartu testimoni yang dibangun sebagai solusi tantangan dari [roadmap.sh]([https://roadmap.sh/](https://roadmap.sh/projects/testimonial-cards)). Fokus utama proyek ini adalah mengimplementasikan berbagai teknik *layouting* dan pemosisian tingkat lanjut menggunakan CSS.

Komponen ini mendemonstrasikan bagaimana kutipan pelanggan atau pengguna dapat ditampilkan dengan cara yang menarik untuk membangun kredibilitas dan kepercayaan pada sebuah website.

## ✨ Variasi Gaya Kartu

Proyek ini mencakup empat teknik desain yang berbeda dalam satu halaman:

1.  **Gaya Speech Bubble:** Menggunakan `position: absolute` dan *pseudo-element* (`::after`) untuk menciptakan efek gelembung percakapan dengan indikator panah yang presisi.
2.  **Gaya Outline Minimalis:** Fokus pada tipografi yang bersih dan penggunaan *border* serta *padding* untuk keterbacaan yang maksimal.
3.  **Gaya Side-by-Side:** Menggunakan Flexbox untuk menggabungkan elemen gambar besar dan area konten gelap, memberikan kontras visual yang kuat.
4.  **Gaya Carousel UI:** Simulasi tampilan *carousel* yang menonjolkan penggunaan *box-shadow*, transformasi skala, dan transparansi untuk membedakan elemen aktif dan tidak aktif.

## 🚀 Fitur Utama

- **Teknik CSS Positioning:** Implementasi `relative` dan `absolute` untuk elemen dekoratif.
- **Responsif:** Menggunakan CSS Grid dan Media Queries untuk memastikan kartu tertata rapi di layar HP maupun Desktop.
- **Desain Modern:** Penggunaan Google Fonts (Inter) dan sistem warna yang kontemporer.
- **Efek Visual:** Penggunaan *hover effect*, *border-radius* yang halus, dan *drop shadow*.

## 🛠️ Teknologi yang Digunakan

- **HTML5** (Struktur semantik)
- **CSS3** (Grid, Flexbox, Positioning, Pseudo-elements)
- **Google Fonts** (Inter)
